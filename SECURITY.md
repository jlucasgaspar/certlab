# Security policy

## Supported versions

Certlab has no public release yet. Only the `main` branch is supported, and security fixes land there.

## Reporting a vulnerability

Do not open a public issue or pull request for a vulnerability.

Report it privately with [GitHub private vulnerability reporting](https://github.com/jlucasgaspar/certlab/security/advisories/new): open the repository's **Security** tab and choose **Report a vulnerability**.

Include what is affected, the steps to reproduce it, and the impact you expect. Never include real credentials or personal data.

The maintainer acknowledges reports on a best-effort basis, as this is a single-maintainer project, and coordinates disclosure with the reporter.

## Leaked credentials

If you find a credential in this repository, its history or a workflow log, report it through the same private channel. Do not use or test it.
